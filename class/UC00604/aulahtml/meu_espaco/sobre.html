Sobre o projeto

Este projeto foi criado para praticar os conceitos básicos de criação de páginas web com HTML.

Aqui posso partilhar o qu estou a aprender na área de informática.

Um portatil usado no dia a dia

Principais objectivos

  1. Aprender a criar páginas web.
  2. Organizar informações de forma clara.
  3. Reutilizar conhecimentos adquiridos.
  4. Explorar novas tecnologias

Conceitos utilizados

HTML
Linguagem de marcação de páginas web.
Hiperligação
Permite ligar diferentes páginas.
Imagem
Mostra imagens no browser.
Lista
Ajuda a organizar informação.
